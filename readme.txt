NinjaFiles - File System Simulator
================================

How to Run the Application
--------------------------

1. Open your terminal or command prompt.

2. Navigate to the `src` directory of the project.
   For example:
   cd src

3. Compile the Java files using the following command:
   javac *.java

4. Run the application using the following command:
   java NinjaFiles

Usage
-----
Once the application is running, you can use the following commands:
- mkdir <name>: Create a new directory.
- mkdir -p <path>: Create a directory and its parents if they don't exist.
- touch <name> <size>: Create a new file with a specified size.
- echo "<text>" > <filename>: Write text to a file.
- ls: List contents of the current directory.
- cd <path>: Change the current directory.
- pwd: Print the current working directory.
- rm <name>: Remove a file or empty directory.
- rm -r <name>: Recursively remove a directory and its contents.
- tree: Display the directory structure as a tree.
- grep "<pattern>" <filename>: Search for a text pattern in a file.
- du: Display the total disk usage of the current directory.
- exit: Exit the application.
- help: Show all available commands.
